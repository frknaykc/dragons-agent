# Changelog

## 0.1.0

Initial public release of Dragons Agent.

- Terminal-native interactive and one-shot coding agent with explicit local READ/WRITE/EXECUTE authorization.
- OpenAI Platform API provider and experimental ChatGPT Subscription provider.
- Streaming, persistent sessions, bounded repository and coding intelligence, Git-aware self-review, and context budgeting.
- Explicit local Skills and Memory, bounded plans, one-level read-only subagents, read-only process-local background tasks, stdio MCP, and local diagnostics.

See the README for current platform status, experimental boundaries, and limitations.
