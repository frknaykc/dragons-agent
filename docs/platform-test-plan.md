2. **Önce bilinen blokajları gider:** Windows `pnpm.cmd` child-process çağrısının güvenli ve shell enjeksiyonuna açık olmayan çözümü (`scripts/release-check.mjs`, `scripts/verify-package.mjs`); Windows goal lock symlink/busy sınırı ve kardeş lock yolları; macOS-only testin Windows uyumu; toplu koşum zaman aşımı/yoğunluk bütçesi. Odaklı regresyonlar yazılıp çalıştırılır, ardından son kaynak tekrar sabitlenir.

Başarısızlık varsa aynı snapshot'ı durmadan tekrar çalıştırmak yerine odaklı tanı yapılır; son maddi düzeltmeden sonra ilgili platform matrisi yenilenir. 4. **Windows x64 paket kapısı:** İzole kopyada `pnpm desktop:pack`; `node scripts/verify-desktop-package.mjs <app.asar>`; `node scripts/verify-windows-packaged-checkpoint.mjs <exe>`; `node scripts/verify-desktop-installed.mjs <exe>`. NSIS install/uninstall, gerçek Credential Manager, login ve updater ayrıca atılabilir Windows oturumu/izinle yapılır; unpacked paket bunların yerine geçmez.
5. **Linux x64 ve ARM64 kapısı:** Docker `linux/amd64` kaynak ve npm paket testi için kullanılabilir; gerçek x64 kanıtı Debian VM'den gelir. ARM64 ayrıca Ubuntu makinede doğrulanır.
